1. ỨNG DỤNG NÀY LÀM GÌ?
-----------------------
Đây là “trợ lý” chạy trên máy Windows có Pi Node. Nó:

  • Theo dõi Node có ổn không (đồng bộ, cổng, Docker, RAM, CPU, nhiệt độ…)
  • Gửi tin nhắn Telegram khi có lỗi — không cần ngồi canh máy
  • Tự quét định kỳ; lỗi nặng (đồng bộ/port) có thể tự reset mạng + Docker
  • Cho phép điều khiển từ xa: dọn RAM, bảo trì, chụp màn hình, hỏi AI…

Đối tượng: người chạy Pi Node (kể cả ít rành máy tính) muốn yên tâm hơn.

3. CÀI ĐẶT NHANH (5–10 PHÚT)
----------------------------
  1. Giải nén thư mục app vào ổ đĩa (vd: C:\PiNode\PiNode Telegram Controller PRO Official)
  2. Chuột phải Start_Controller.bat → Run as administrator (lần đầu khuyến nghị)
  3. Chọn [1] hoặc [3] để nhập Key:
        - Telegram Bot Token
        - Chat ID
        - Gemini API Key
        - Phút quét (mặc định 60) · ngưỡng RAM (mặc định 88)
     Nhấn Enter = giữ giá trị cũ / mặc định
  4. Chọn chạy Controller
  5. Telegram sẽ nhận menu mở đầu (1 lần) + QR ủng hộ (1 lần)
  6. Gửi /status hoặc /monitor để thử


4. CÁC LỆNH TELEGRAM
--------------------
  TÌNH TRẠNG
    /status      Xem Node ổn hay cần xem (nhanh, lấy dữ liệu lần quét gần nhất)
    /monitor     Kiểm tra ngay: đưa PiCheck lên, chụp, AI đọc số
    /report      Báo cáo 24 giờ
    /scheduler   Xem lịch tự động

  BẢO TRÌ
    /cleanram    Dọn RAM: tắt app rác, xóa Temp, flush DNS
                 KHÔNG tắt Pi Node / Docker
    /maintenance Bảo trì tuần (cần /confirm): dọn rác, Docker prune,
                 anti-sleep, TRIM, SFC đầu tháng nếu đúng lịch
    /reset       Reset mạng + Node (cần /confirmreset):
                 troubleshoot mạng, gắn IP tĩnh = IP đang dùng,
                 mở port 31401–31410, reset Docker/WSL
                 Dùng khi không đồng bộ / port đóng / lỗi mạng
    /diagnostic  Chẩn đoán nhanh
    /cancel      Hủy lệnh đang chờ xác nhận

  HỆ THỐNG
    /docker · /disk · /logs · /screenshot

  KHÁC
    /ask <câu hỏi>  Hỏi Hermes AI (nếu đã cấu hình)
    /donate         Gửi lại QR ủng hộ
    /help           Menu lệnh


5. VIỆC TỰ ĐỘNG (KHÔNG CẦN BẤM)
-------------------------------
  • Mỗi 60 phút: quét Node (im lặng nếu ổn)
  • Khi phát hiện lỗi: báo Telegram + quét lại mỗi 10 phút
  • Lỗi đồng bộ / port / mạng liên tiếp 3 lần: tự chạy /reset
  • 07:00 và 18:00: gửi báo cáo 24 giờ
  • Chủ nhật 23:00: bảo trì tuần (im lặng nếu thành công)


6. GỢI Ý SỬ DỤNG HÀNG NGÀY
--------------------------
  • Để PiCheck và Pi Desktop mở (hoặc có thể mở khi /monitor)
  • Nên chạy Controller bằng Start_Controller.bat hoặc cài task
    (Install_Controller_Task.bat) để tự chạy khi bật máy
  • Khi Node báo đỏ: đọc tin cảnh báo → /monitor → nếu vẫn lỗi /reset
  • /cleanram khi máy nặng RAM; /maintenance khoảng 1 lần/tuần nếu muốn thủ công


7. CẤU TRÚC THƯ MỤC
-------------------
  Start_Controller.bat     Mở app (menu nhập Key / chạy)
  Setup_Config.bat         Chỉ nhập Key

  State\                   Trạng thái lịch, cờ welcome


8. XỬ LÝ SỰ CỐ THƯỜNG GẶP
-------------------------
  • Bot không trả lời: kiểm tra Token/Chat ID, đã Start_Controller chưa,
    xem Logs\controller.log
  • /monitor ra N/A: thiếu Gemini API Key, hoặc PiCheck chưa mở
  • Lỗi font tiếng Việt: dùng bản đã sửa UTF-8 (file .ps1 có BOM)
  • /reset không đổi IP: cần chạy Controller / script với quyền Admin
  • Muốn hiện lại menu + QR lần đầu: xóa file State\welcome_sent.flag
    rồi restart Controller
